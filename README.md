## ⭐ Featured projects

### 🍽️ [Obiadowo](https://github.com/majkab8/Conaobiad) · [live demo](https://obiadowo.vercel.app)
AI recipe assistant for Polish cuisine. Built as a **RAG** pipeline over ~200 recipes stored in Pinecone.
The steps are written by **my own fine-tuned Polish LLM**. I distilled Bielik-11B into Bielik-1.5B with **LoRA**
and published the model on the [Hugging Face Hub](https://huggingface.co/Mijuub/conaobiad-polka).

`FastAPI` · `React` · `Pinecone` · `transformers` · `peft` · `HF Spaces` · `Vercel`

### 👗 [DressUP: fashion classification model](https://github.com/majkab8/DressUP---classification-model)
Multi-head **EfficientNet-B0** classifier that tags clothing photos with type, colour, usage and season.
It reaches 93% accuracy on usage and 89% on type. Served as a **FastAPI** endpoint in Docker on **Azure Container Apps**.

`PyTorch Lightning` · `FastAPI` · `Docker` · `Azure`

### 🧝 [English → Elvish translator](https://github.com/majkab8/ELF-language-translator)
Fine-tuned Helsinki-NLP MarianMT model that translates English into Tolkien's Quenya.
It was trained on 10k word pairs from the Eldamo lexicon. You can use it from the CLI or from a Flask web page.
Model is on [Hugging Face Hub](https://huggingface.co/Mijuub/eldamo-en-elvish).

`transformers` · `PyTorch` · `Flask`

### 🎧 [DJ Adriano: website for a client](https://github.com/majkab8/DJ-site) · [live](https://adrianodj.pl)
Responsive one-page promo site for a wedding DJ. Hand-written HTML/CSS with no frameworks.
It's deployed on Vercel with a custom domain.

`HTML` · `CSS` · `Vercel`
